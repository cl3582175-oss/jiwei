# v0.4 学习闭环：设计

状态：实施中（2026-10-09）。v0.4.0、v0.4.1 已完成。v0.3 让积微能“懂你”，v0.4 让学到的东西真正留下来：记得住（复习）、讲得出（费曼）、想得透（复盘）。

## 1. 闭环

```
记录（康奈尔笔记）→ 复习（线索问题，FSRS）→ 讲出来（费曼，找漏洞）→ 复盘（素材包 + 追问）
       ↑                                                                   │
       └──────── 洞见、行动项、补充线索 ←──────────────────────────────────────┘
```

所有环节的信号都回到同一个学习者模型（v0.3.4 的 `concepts` / `concept_events`）：复习忘了、费曼讲不清 → 薄弱；复习记得、讲清楚了 → 牢固。

## 2. 复习（v0.4.0）

- **卡片来源**：康奈尔笔记中有线索的每一行自动成为一张卡片。问题 = 线索栏，答案 = 同一行的笔记栏。卡片跟着行走：
  - 线索被改，卡片的复习进度保留。
  - 行被删，卡片随之删除（软删除）；行恢复，卡片也恢复。
- **不想复习的**：
  - 单张卡片可以暂停。
  - 整篇笔记可以设为“不复习”，之后新增的线索也不再成卡。
- **调度**：采用 ts-fsrs（FSRS 官方实现，MIT），不自己造。
  - 四档评分：忘了 / 困难 / 记得 / 轻松。按钮上显示下次间隔。
  - 目标记忆保持率默认 90%，每天新卡上限默认 20 张，均可在设置中调整。
- **复习界面**：侧栏新增「复习」，徽标显示到期卡片数。
  - 先看问题，可以在心里想或写下回答，再显示答案。答案用 Markdown 渲染，富内容块以文字形式显示。
  - 键盘：空格显示答案，1～4 评分。
  - 可以跳到笔记中的这一行，也可以暂停这张卡。
  - 结束时显示本次统计和明天的数量。
- **与学习者模型联动**：问题中出现的已知概念，“忘了”记一次没弄懂，“记得 / 轻松”记一次理解。
- **AI 检查回答**（写下回答时可用）：模型对照笔记指出遗漏和偏差，并建议一个评分。最终评分仍由用户决定。

## 3. 费曼模式（v0.4.1）

- 入口：
  - 笔记中选中概念 →「讲给 AI 听」。
  - 「学习情况」中的薄弱概念。
  - 复习卡片 →「用自己的话讲一遍」。
- AI 扮演一个聪明但完全不懂的学生，按技能 `feynman` 的流程：
  1. 请你讲。
  2. 针对模糊、跳步、术语未解释处追问（每次一个问题）。
  3. 你讲清楚后总结漏洞。
- 结束后：
  - 输出“讲清楚了什么、哪里还不清楚”。
  - 概念信号写入学习者模型。
  - 可以把漏洞变成新的线索问题（提案），进入复习。

## 4. 复盘（v0.4.2）

- **每日微复盘（1 分钟）**：今天学了什么、一个还没想明白的点、明天做一件什么事。素材是当天的笔记、学习经历和复习情况。
- **每周完整复盘**：
  - 采用 GRAI 模板：目标、结果、分析、洞见。
  - 素材包：本周笔记与段落时间戳、学习经历、复习表现（忘得最多的卡片）、没有回答的线索、概念掌握度变化、上周行动项的完成情况。
  - AI 用苏格拉底式追问帮你想深一层，不替你写结论。
  - 复盘正文是一篇 `kind = review` 的笔记，记录在 `reviews` 表。
- **专题复盘**：针对某个主题、某次实践或某个看法的变化。
- **洞见**：
  - 带版本、证据和把握程度（假设 / 相信 / 已验证）。
  - 被修正时留下版本和原因，形成认知成长轨迹。
- **行动项**：有截止日期；下一次复盘时检查是否完成，形成闭环。
- 提醒时间沿用已有的 `reflection` 设置。

## 5. 学习目标与掌握度地图（v0.4.3）

- 学习目标关联分类、笔记和概念，复盘与复习统计可以按目标查看。
- 掌握度地图：按分类和笔记聚合概念与卡片的掌握情况，标出牢固、薄弱和空白（有笔记无卡片、有卡片从未复习）。完整的知识图谱在 v0.5。
- 重排序模型评估：用复习和复盘的真实检索需求评估是否引入。
