# v0.3 设计：懂用户、会用技能的学习智能体

状态：已确认（2026-10-08）。实施顺序为 v0.3.0 → v0.3.4，随后进入 v0.4 学习闭环。

## 1. 原则

- **指，而不是描述**：用户选中、框选、暂停或点按，界面自动生成「上下文包」，用户只需表达意图。
- **一个内核，三个入口**：就地卡片、工作区 AI 面板、独立对话共用同一套上下文、技能、记忆和工具。
- **模型产出数据，成熟库负责呈现**：技能约束输出格式，经校验后交给渲染器，确保能力较弱的模型也能做出合格结果。
- **所有写入走提案**：AI 修改笔记前，用户逐条确认。

## 2. 上下文包与锚点

```ts
ContextPacket {
  targets: Anchor[]          // 用户指向的内容（选区 / 内容块 / 时间段 / 画面）
  surroundings: string[]     // 前后文、章节标题、资料名
  viewport?: Anchor          // 未选中时：当前可见的页或片段
  workspace: { noteId?, sourceId?, cursorBlockId? }
  image?: AssetRef           // 框选的图片或视频画面
}
Anchor {
  kind: 'source-text' | 'note-text' | 'block' | 'embed' | 'media-range' | 'region'
  parentId, segmentId? | blockId?, start?, end?
  quote, prefix, suffix        // W3C TextQuote，资料更新后用于重新定位
  page?, rect?, t?: [start, end]
}
```

输入框上方以标签显示上下文包的每一项，用户可以逐项移除。

| 情境 | 交互 | 上下文 |
| --- | --- | --- |
| 概念不懂 | 选中词 → 解释 | 词、句、段、章节，用户水平（记忆），知识库中的相关内容 |
| 论述不懂 | 选中段 → 讲明白 / 举例 / 画成图 | 段落及前后 1～2 段、页码 |
| 整页不懂 | 不选中，直接提问 | 当前可见内容 |
| 图、公式、表格 | 框选区域 | 截图（看图模型）；不支持看图时使用文字层 |
| 修改笔记 | 选中或点内容块 → 快捷改写 / 自由指令 | 选区、所在康奈尔行、关联资料；内容块的结构化数据 |
| 生成 | 光标处 + 自然语言 / @引用 | 插入点、当前资料、可见页 |

## 3. 视频与音频

### 3.1 转写稿是视听资料的「文字层」

后台任务 `source.transcribe` 的流程：

1. 如果资料带有字幕（同名 `.srt` / `.vtt`，或用户导入），直接使用字幕，跳过识别。
2. 否则用 ffmpeg 提取 16 kHz 单声道音频。ffmpeg 按需下载，复用多镜像下载器。
3. 本地识别：sherpa-onnx（`sherpa-onnx-node` 提供三平台预编译包）+ Silero VAD 切句 + SenseVoice-Small int8。模型约 230 MB，从 ModelScope 下载，支持中、英、日、韩、粤，自带标点。运行在工作进程中，速度远快于实时。
4. 也可以改用云端识别，即 OpenAI 兼容的 `/audio/transcriptions` 接口（带时间戳）。云端识别需要上传音频，界面会明确提示。
5. 句子 `{start, end, text}` 按停顿或每段不超过 60 秒合并为片段，`locator = t=start,end`，然后进入知识库索引。
6. 转写稿可以修改（纠正识别错误），时间信息保持不变，修改后重新索引。
7. AI 根据转写稿自动生成章节，章节标题用于导航，也作为上下文。

### 3.2 怎么「指」

| 交互 | 上下文 |
| --- | --- |
| 播放器旁的转写稿与播放同步（当前句高亮，点句子跳转）；选中文字 → 与文本资料相同的浮条 | 选中的句子及前后文、时间段、章节 |
| 「没听懂」按钮或快捷键：自动暂停 | 当前时间之前 30 秒到之后 5 秒的转写稿。时间范围在进度条上显示，可以拖动调整 |
| 在进度条上拖出 A–B 区间 → 提问 | 区间内的转写稿 |
| 「问这个画面」（仅视频）：截取当前帧，可再框选局部 | 画面图像（看图模型）+ 前后 15 秒转写稿；不支持看图时只用转写稿，并提示用户 |
| 播放中直接在输入框提问（例如“他刚才说的 X 是什么”） | 自动附带「🎬 12:05 前后」时间标签 |

### 3.3 锚点与回看

- 锚点记录时间段 `t=[start, end]`。提问会在进度条和转写稿上留下标记点。
- 「存入笔记」生成一行康奈尔笔记，附带 `▶ 12:05` 时间链接，点击后打开资料并从该处播放。
- 对话中的引用点击后跳到对应时间并开始播放。
- 音频与视频的交互相同，只是没有画面相关功能。

### 3.4 暂不做

在线视频链接（B 站、YouTube）的字幕获取、关键帧和幻灯片文字识别、说话人分离，都放到后续版本。

## 4. 对话的呈现

1. **就地卡片**：选区旁的浮条与流式卡片，提供「追问」「存入笔记」「复制」。
2. **工作区 AI 面板**：平时是右下角按钮；展开后为浮动玻璃面板；可以钉住为右侧抽屉，钉住时自动收起第 2 栏。
3. **独立对话页**：跨整个知识库的分析、报告和 PPT。

带锚点的对话会在原文边缘留下标记，点击可以回到当时的对话。

## 5. 记忆

| 类别 | 内容 | 来源 |
| --- | --- | --- |
| ① 个人档案 | 身份、学习目标、各领域基础、回答偏好、不要记住的事 | 用户预设（引导问题 + 设置） |
| ② 偏好与事实 | 学习情况、习惯、偏好 | 每次对话结束后，后台抽取，并与已有记忆比对，决定新增、更新、作废或忽略 |
| ③ 学习者模型 | 每个概念的掌握度、卡点、复习表现 | 行为信号 |
| ④ 学习经历 | 每次学习的摘要 | 会话结束时生成，也是复盘素材 |
| ⑤ 技能偏好 | 对某个技能输出的稳定偏好 | 对比 AI 输出与用户修改，统计提案被拒绝的情况 |
| ⑥ 术语表 | 用户的简称、自造词、领域缩写 | 用户添加，或 AI 询问一次后记住 |

- **常驻用户卡片**：不超过 600 token，放在提示固定前缀中，会话开始时更新，以便命中缓存。
- **深层记忆**：通过 `memory.search` 工具按需检索。
- **自动记住**：普通偏好自动记住，并提示，可以撤销；敏感类（健康、财务、人际）先询问再记。另有无痕对话模式。
- **管理**：长期不用的记忆淡出归档；每条记忆都有来源证据。
- **归属**：记忆属于“人”，不属于知识库，不随共享知识库同步。全部存储在本地。

## 6. 技能

- 格式采用 Agent Skills 开放标准（`SKILL.md`），以便导入社区技能，并可改编 Apache-2.0 许可的 anthropics/knowledge-work-plugins（保留署名）。
- 一个技能 = 说明 + 输出格式（zod）+ 渲染器 + 校验与修复 + 示例。可以声明最低模型能力，自由 HTML 交互只对强模型开放，其他模型降级为模板。
- 采用渐进加载：平时只携带名称和简介，选用时才加载正文。
- 技能偏好（记忆 ⑤）附加在对应技能之后。
- 长任务使用 AI SDK 的多步工具循环：先列计划，分步执行，显示进度，可以暂停或取消。

## 7. 提示结构（缓存友好）

1. `[系统说明 + 技能目录 + 用户卡片]`：稳定前缀，可以命中缓存。
2. `[会话历史]`
3. `[本轮上下文包 + 检索结果 + 已加载技能]`
4. `[问题]`

小任务（路由、记忆抽取、章节生成）使用 flash 模型并关闭思考。
