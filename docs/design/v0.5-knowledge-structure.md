# v0.5 知识结构与标注：设计

状态：已完成（2026-10-10）。v0.5.0–v0.5.3 已完成。v0.3 让积微懂你，v0.4 让学到的留下来，v0.5 让知识**连起来**：笔记之间的关系看得见，读资料时可以随手批注。

## 1. 已有基础

- `links` 表：笔记到笔记、资料、网址。`origin` 区分正文派生（doc）和手动建立（manual），`relation` 已预留：引用、相关、取代、证据、派生、矛盾、应用。正文中的 `jiwei://note/<id>` 链接已在派生时写入。
- `annotations` 表：W3C Web Annotation 数据模型。选择器支持文字引用、PDF 页、媒体时间段、笔记段落；`motivation` 包括高亮、评论、绘制、书签、提问。
- 路线图中“笔记与资料锚点”“音视频转写”已在 v0.3.1 完成：出处链接带页码、时间点、段落；转写使用 SenseVoice 本地模型或 OpenAI 兼容的云端接口。

## 2. 双向链接（v0.5.0）

- **写链接**：在笔记中输入 `[[` 弹出笔记与资料的搜索列表（Tiptap Suggestion）。选中后插入带链接的标题；没有找到时可以直接新建一篇笔记并链接过去。
- **反向链接**：笔记底部的「关联」区，包括：
  - **链接到这里**：哪些笔记链接了本篇，显示所在段落，点击跳到那一段。
  - **相关笔记（推荐）**：按内容相似度找出的相关笔记与资料，用本地向量，不调用大模型、不花钱。显示最相似的一对段落作为理由。点“关联”建立手动的相关关系（双向可见），点“不相关”以后不再推荐。
  - **未链接的提及**：正文里出现了本篇标题、但没有链接的笔记，可以一键关联。
- AI 对话中，知识库检索结果和工具已经可以看到这些链接。v0.5.1 的知识结构图会用到全部关系。

## 3. 知识结构图（v0.5.1）

- 采用 sigma.js（WebGL）+ graphology + ForceAtlas2 布局（在 Web Worker 中计算），不自己写渲染。
- 节点：笔记、资料，可选显示概念。连线：正文链接、手动关联、笔记引用的资料出处。
- 着色可切换：按分类，或按掌握度（沿用 v0.4.3 的地图规则：薄弱、空白一眼可见）。
- 交互：搜索并聚焦、悬停高亮邻居、点击打开笔记；在笔记中可以打开“局部图”（只看与本篇相距两步以内的节点）。

## 4. 批注（v0.5.3）

### 4.1 设计修订：统一的批注层，不用 pdf.js 批注编辑器保存数据

原计划用 pdf.js 自带的批注编辑器。实施前评估了 pdfjs-dist 6.4 的组件，结论是不合适：

- 编辑器的修改保存在 PDF 文件内部（需要另存一份带批注的副本）。积微无法检索这些批注，AI 也看不到，复盘也用不上。
- 编辑器的“评论”功能属于 pdf.js 的完整阅读器应用，可复用的组件中没有。
- PDF、文字资料、转写稿、笔记会变成三套不同的批注交互。

因此改为积微自己的批注层：

- 所有批注存入 `annotations` 表，统一采用 W3C Web Annotation 模型。选择器包括：原文引用（TextQuote，带前后文）、片段或段落 ID、页码、页内矩形、媒体时间段。
- 导出 PDF 时，用 pdf-lib 把高亮和评论写成标准 PDF 批注（Highlight、带 Contents），可以在“预览”、Acrobat 中查看和继续编辑。
- 手绘批注不在本版本范围内。

### 4.2 交互

- **选中文字**：浮条在“解释 / 讲明白 / 翻译 / 问 AI”之外，增加
  - “高亮”：四种颜色；
  - “批注”：高亮并写一条评论；
  - “存疑”：标为“有疑问”，进入复盘。
- **点击高亮**：弹出小卡片，可以编辑评论、换颜色、删除（可撤销），或就这段问 AI。
- **批注列表**：资料顶部的“批注”按钮打开列表，按页码或位置排序，可筛选，点击跳到原文。
- **笔记**：段落右侧的批注气泡，可以写评论或提问，不改动正文；把鼠标移到段落上即可添加。

### 4.3 定位

- **PDF**：页码 + 页内相对矩形（缩放后仍然准确），同时保存原文。
- **文字资料、转写稿**：片段 ID + 原文 + 前后文。资料重新解析后，先在原片段中查找原文，找不到再在全文中查找；仍找不到的批注标为“失去定位”，在列表中保留。显示使用浏览器的 CSS Custom Highlight API，不改动 DOM。
- **笔记**：段落 ID（blockId），并保存原文以便核对。

### 4.4 进入知识库与复盘

- 有评论或提问的批注作为独立分片进入检索（向量 + 关键词）。AI 引用时显示为“［批注］评论（原文：……）”，跳回原文位置。
- 每周复盘素材包列出本期新增的批注；“存疑”的批注作为未解决的问题。
- 资料或笔记设为“不发送给 AI”时，它的批注也不进入检索。
