- [x] Playwright 端到端测试；GitHub Actions CI 与三平台发布流程

## v0.2 知识库与 AI 对话 ✅

知识库 = 你写的笔记 + 你上传的原始资料。

- [x] 模型服务管理：DeepSeek（默认）、OpenAI、Anthropic、Gemini、通义、Kimi、智谱、Ollama 本地模型，以及任意 OpenAI 兼容接口；测试连接、拉取模型列表
- [x] API Key 使用系统钥匙串加密保存，界面只显示末四位
- [x] 思考强度：关闭 / 低 / 中 / 高 / 极限，统一档位映射到各家参数，只显示当前模型支持的档位；对话输入框一键切换
- [x] 资料解析：PDF（按页）/ EPUB / Word / Markdown / 网页正文
- [x] 内置向量模型 EmbeddingGemma 2（llama.cpp 运行，多镜像测速下载、慢速自动切换、断点续传、sha256 校验）；也可改用云端向量服务
- [x] 向量索引（sqlite-vec）+ 关键词混合检索（RRF 融合）+ 时间与可信度权重；“不让 AI 读取”的内容不进入检索
- [x] 独立 AI 对话：全部知识库 / 指定笔记与资料 / 不使用知识库
- [x] 回答带引用溯源，点击跳回笔记段落或资料片段（PDF 定位到页）
- [x] 区分“来自你的知识库”与“模型通用知识”；展示思考过程
- [x] Token 用量、思考 token 与费用估算；可随时停止生成
- [x] 端到端测试使用真实 DeepSeek 服务验证（需要用户本地配置，CI 中跳过）
