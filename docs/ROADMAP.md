# 积微路线图

## v0.1 地基 ✅

- [x] Electron + React + TypeScript 工程，Git 管理，PolyForm Noncommercial 许可
- [x] SQLite 数据层，Drizzle 迁移（保证版本升级时数据平滑迁移）
- [x] 康奈尔笔记编辑器（线索 / 笔记 / 总结），自动保存，富文本格式
- [x] 笔记：新建、分类、排序、检索（FTS5 中文全文检索）、置顶、删除
- [x] 资料库：导入文件（对话框 / 拖拽）、添加网址、按类型和分类筛选、检索、重命名、删除
- [x] 最近删除：确认弹窗 → 保留 30 天 → 自动永久删除；支持还原和手动永久删除
- [x] 学习热力图、连续学习天数
- [x] 设置：语言（中 / 英）、主题（系统 / 浅 / 深）、五种强调色、数据目录
- [x] 命令面板（⌘K）与全局快捷键
- [x] Playwright 端到端测试；GitHub Actions CI 与三平台发布流程

## v0.1.1 数据地基重构 ✅

- [x] 康奈尔单文档模型：行（线索 + 笔记）横向绑定 + 总结；⌘Enter 新增行，Tab 切换

- [x] 段落永久 ID + 段落级时间戳（悬停一行可见修改时间）
- [x] 学习日期、知识状态（有效 / 存疑 / 已过时）、“被取代”关系
- [x] 版本历史：自动快照 + 手动保存 + 预览 + 恢复
- [x] 嵌套分类、标签；删除分类可撤销、进入最近删除
- [x] 内容寻址素材仓库 + jiwei:// 协议；笔记内粘贴 / 拖入图片；资料去重
- [x] 资料信息：作者、发布日期、获取日期、标签
- [x] 关联表、W3C 批注表（结构就绪）
- [x] 隐私：笔记 / 资料可设为“不发送给 AI”
- [x] 数据安全：每日自动备份、迁移前备份、数据目录迁移、云盘警告、退出保存握手

- [x] Vitest 单元测试 + 10 项端到端测试（含重启持久化）

## v0.2 知识库与 AI 对话 ✅

知识库 = 你写的笔记 + 你上传的原始资料。

- [x] 模型服务管理：DeepSeek（默认）、OpenAI、Anthropic、Gemini、通义、Kimi、智谱、Ollama 本地模型，以及任意 OpenAI 兼容接口；测试连接、拉取模型列表
- [x] API Key 使用系统钥匙串加密保存，界面只显示末四位
- [x] 思考强度：关闭 / 低 / 中 / 高 / 极限，统一档位映射到各家参数，只显示当前模型支持的档位；对话输入框一键切换
- [x] 资料解析：PDF（按页）/ EPUB / Word / Markdown / 网页正文
- [x] 内置向量模型 EmbeddingGemma 2（llama.cpp 运行，多镜像测速下载、慢速自动切换、断点续传、sha256 校验）；也可改用云端向量服务
- [x] 向量索引（sqlite-vec）+ 关键词混合检索（RRF 融合）+ 时间与可信度权重；“不让 AI 读取”的内容不进入检索
- [x] 独立 AI 对话：全部知识库 / 指定笔记与资料 / 不使用知识库
- [x] 回答带引用溯源，点击跳回笔记段落或资料片段（PDF 定位到页）
- [x] 区分“来自你的知识库”与“模型通用知识”；展示思考过程
- [x] Token 用量、思考 token 与费用估算；可随时停止生成
- [x] 端到端测试使用真实 DeepSeek 服务验证（需要用户本地配置，CI 中跳过）
- [ ] 重排序模型（移至 v0.3，与 AI 创作一起评估）
