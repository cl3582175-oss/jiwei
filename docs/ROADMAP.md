# 积微路线图

## v0.1 地基 ✅

- [x] Electron + React + TypeScript 工程，Git 管理，PolyForm Noncommercial 许可
- [x] SQLite 数据层，Drizzle 迁移（保证版本升级时数据平滑迁移）
- [x] 康奈尔笔记编辑器（线索 / 笔记 / 总结），自动保存，富文本格式
- [x] 笔记：新建、分类、排序、检索（FTS5 中文全文检索）、置顶、删除
- [x] 资料库：导入文件（对话框 / 拖拽）、添加网址、按类型和分类筛选、检索、重命名、删除
- [x] 最近删除：确认弹窗 → 保留 30 天 → 自动永久删除；支持还原和手动永久删除
- [x] 学习热力图、连续学习天数
- [x] 设置：语言（中 / 英）、主题（系统 / 浅 / 深）、五种强调色、数据目录
- [x] 命令面板（⌘K）与全局快捷键
- [x] Playwright 端到端测试；GitHub Actions CI 与三平台发布流程

## v0.1.1 数据地基重构 ✅

- [x] 康奈尔单文档模型：行（线索 + 笔记）横向绑定 + 总结；⌘Enter 新增行，Tab 切换
- [x] Yjs CRDT 存储正文（为多设备同步 / 多人协作预留），追加写入 + 自动压缩
- [x] 段落永久 ID + 段落级时间戳（悬停一行可见修改时间）
- [x] 学习日期、知识状态（有效 / 存疑 / 已过时）、“被取代”关系
- [x] 版本历史：自动快照 + 手动保存 + 预览 + 恢复
- [x] 嵌套分类、标签；删除分类可撤销、进入最近删除
- [x] 内容寻址素材仓库 + jiwei:// 协议；笔记内粘贴 / 拖入图片；资料去重
- [x] 资料信息：作者、发布日期、获取日期、标签
- [x] 关联表、W3C 批注表（结构就绪）
- [x] 隐私：笔记 / 资料可设为“不发送给 AI”
- [x] 数据安全：每日自动备份、迁移前备份、数据目录迁移、云盘警告、退出保存握手
- [x] UUIDv7 + 同步字段；渲染进程沙箱化；日志
- [x] Vitest 单元测试 + 10 项端到端测试（含重启持久化）

## v0.1.2 模型与架构地基 ✅

- [x] 能力注册表（zod）：IPC、preload、类型由注册表生成，主进程统一校验参数；AI 工具定义可导出
- [x] 数据结构：笔记类型、资料分段、块来源、用户与设备、目标、复盘、洞见及版本、行动项、复习卡片、学习者画像、提案、任务
- [x] 富内容块框架（数据存于 Yjs，可协作）+ 思维导图（显示、转文字检索、展开为康奈尔行、节点原文锚点）
- [x] 内容来源：AI 内容有标记；用户修改后自动标为“已审阅”；未审阅的 AI 字数不计入学习统计
- [x] AI 修改提案：逐条预览、接受或拒绝、可撤销；隐私笔记拒绝 AI 修改
- [x] 后台任务：持久化队列、重试、重启续跑、独立工作进程；Markdown 和文本资料自动分段
- [x] 双栏工作区（资料 | 笔记，可拖动）、资料内阅读（文本、图片、音视频、PDF）、导航历史（⌘[ / ⌘]）、深层链接
- [x] 工作区上下文（光标所在块、选中文字、资料位置和选区），供 AI 使用
- [x] 多知识库（新建、打开、切换）、你的名字（协作署名）
- [x] `.jiwei` 交换格式规范（docs/FORMAT.md）
- [x] ESLint + Prettier + EditorConfig；单元测试 15 项、端到端测试 19 项

- [x] 篆刻印章标志；水墨线描插画（空状态、引导页）

- [x] 友好的空状态与零值文案、线索栏“?”说明、保存时盖章动效、连续学习里程碑庆祝
- [x] 单元测试 17 项、端到端测试 20 项
