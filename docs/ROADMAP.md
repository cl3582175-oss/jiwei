# 积微路线图

## v0.1 地基 ✅

- [x] Electron + React + TypeScript 工程，Git 管理，PolyForm Noncommercial 许可
- [x] SQLite 数据层，Drizzle 迁移（保证版本升级时数据平滑迁移）
- [x] 康奈尔笔记编辑器（线索 / 笔记 / 总结），自动保存，富文本格式
- [x] 笔记：新建、分类、排序、检索（FTS5 中文全文检索）、置顶、删除
- [x] 资料库：导入文件（对话框 / 拖拽）、添加网址、按类型和分类筛选、检索、重命名、删除
- [x] 最近删除：确认弹窗 → 保留 30 天 → 自动永久删除；支持还原和手动永久删除
- [x] 学习热力图、连续学习天数
- [x] 设置：语言（中 / 英）、主题（系统 / 浅 / 深）、五种强调色、数据目录
- [x] 命令面板（⌘K）与全局快捷键
- [x] Playwright 端到端测试；GitHub Actions CI 与三平台发布流程

## v0.2 知识库与 AI 对话

- [ ] 模型服务管理：DeepSeek（默认）、OpenAI、Anthropic、Gemini、通义、Kimi、智谱、Ollama 本地模型，以及任意 OpenAI 兼容接口
- [ ] API Key 使用系统钥匙串加密保存
- [ ] 资料解析：PDF / EPUB / Word / Markdown / 网页正文
- [ ] 向量索引（sqlite-vec）+ 关键词混合检索 + 重排序
- [ ] 独立 AI 对话：可选择一篇或多篇笔记、资料作为上下文
- [ ] 回答带引用溯源，点击跳回笔记段落或资料页码
- [ ] 区分“来自你的知识库”与“模型通用知识”
- [ ] Token 用量与费用统计

## v0.3 编辑区 AI 助手

- [ ] 编辑区右下角 AI 输入框，用自然语言操作当前笔记
- [ ] 生成表格、图片、Mermaid 图、代码
- [ ] 生成可交互组件与代码动画（沙箱运行）
- [ ] 根据笔记栏自动生成线索问题和总结
- [ ] 笔记导出：Markdown / PDF / Word / HTML

## v0.4 结构化与标注

- [ ] 笔记双向链接，AI 推荐关联
- [ ] 知识结构图（WebGL 力导向图），点击进入笔记
- [ ] 标注画布层：在笔记和资料上自由批注、圈画、备注
- [ ] 笔记与资料锚点：引用到页码、时间戳、段落
- [ ] 音视频转写（Whisper），带时间戳

## v0.5 学习闭环

- [ ] 间隔复习（FSRS 算法），线索栏问题自动成为复习卡片
- [ ] 费曼模式：AI 扮演学生追问，找出知识漏洞
- [ ] 掌握度地图：在知识图谱上显示牢固、薄弱与空白区域
- [ ] 学习周报自动生成
