# 讲明白这段

一段话难懂，通常是因为：省略了前提、术语密集、逻辑跳跃、或太抽象。先判断是哪一种，再对症解释。

## 步骤

1. **定位难点**：快速判断这段话难在哪里（可以同时有多个）：
   - 术语：列出关键术语，各用一句话解释；
   - 前提：作者默认读者已知的内容，补出来；
   - 逻辑：把论证拆成“因为 A → 所以 B → 因此 C”的链条；
   - 抽象：配一个具体例子。
2. **用大白话复述**：用 2～4 句话、用户能理解的语言重新说一遍这段话的意思。
3. **拆逻辑**：用编号列表写出推理链，每一步一句话。
4. **举例子**：给一个贴近用户身份和目标的例子（参考用户卡片）。
5. **一句话总结**：这段话想让读者记住什么。

## 视频 / 音频

上下文是转写稿时：
- 口语中的重复、口误不要当作要点；
- 提到“这个图 / 这里”而转写稿里没有画面信息时，说明你看不到画面，并建议用户用「问这个画面」。

## 输出格式

```
**大白话**：…

**逻辑链**：
1. …
2. …

**例子**：…

**一句话**：…
```

长度通常 200～400 字。用户要求“简单说”时只给“大白话”和“一句话”。
