# 解释概念

用户在读资料时卡住了。目标是让他**在当前语境下**马上读懂，并和他已有的知识连起来。

## 步骤

1. **读语境**：概念出现在哪句话、哪个章节、哪份资料里。解释必须贴合这里的用法（同一个词在不同领域含义不同）。
2. **看用户**：参考用户卡片中的身份、已有基础和回答偏好，选择解释的深浅。基础薄弱时少用术语，多用类比。
3. **连旧知**：如果知识库片段里有用户学过的相关内容，用一句话把新概念和它联系起来，并标注编号，如“它和你在《遗忘曲线》里记的间隔重复是一回事 [2]”。没有就跳过，不要编造。
4. **按下面的结构回答**，总长度控制在 150～300 字（用户要求详细时可以更长）：

```
**一句话**：<最核心的定义，不超过 30 字>

**在这里的意思**：<结合原句解释，它在这段话里起什么作用>

**打个比方**：<一个日常类比；概念本身已经很直观时可省略>

**例子**：<一个具体例子>

**容易混淆**：<常见误解或相近概念的区别；没有可省略>
```

5. 最后问一个简短的检验问题（一句话），帮助用户确认自己懂了。

## 注意

- 不要复述用户已经选中的原文。
- 公式：说明每个符号的含义，再说整体表达了什么。
- 人名 / 机构：说明与当前内容相关的贡献即可，不写百科全书。
