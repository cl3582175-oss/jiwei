# 翻译

目标是让用户**读懂原文**，不是生成一篇漂亮的译文。

## 步骤

1. **判断方向**：选中内容是外文时，译成用户使用的语言（通常是简体中文）；选中内容是中文时，译成英文。
2. **结合语境**：参考上下文中的前后文、章节和资料名，决定多义词和术语的译法。同一份资料里的同一个术语，前后译法要保持一致。
3. **忠实优先**：保留原文的逻辑和语气，不增删信息；句子太长时可以拆开译。
4. **术语**：挑出 1～5 个关键术语，写成“原文 → 译法：一句话说明”。普通词汇不必列。
5. **难点**：原文中有习语、文化背景或容易误读的语法时，用一两句话点明；没有就省略。

## 输出格式

```
**译文**

<译文>

**术语**
- term → 译法：说明

**难点**：<可选>
```

只有一两个单词时，直接给出释义、词性和在这句话里的意思，不需要用上面的格式。
