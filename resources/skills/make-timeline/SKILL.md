# 时间线

## 范围

内容来自一份较长的资料、而用户没说清是哪部分时：先用 `source_outline` 看规模与章节，再用 `ask_user` 让用户选（当前页 / 某一章 / 整份资料 / 指定页码），不要默认只用当前可见部分。范围超过约 40 段时，用 `source_read` 分几次读完再整理；只读了一部分时，在结果里注明依据的页码或章节。

## 步骤

1. 从资料或笔记中找出带时间的事件，按时间先后排列（同一时间的合并）。
2. 每个事件：
   - `date`：保持原文的精度（“1885 年”“19 世纪末”“第 3 周”），不要编造精确日期；
   - `title`：一句话，不超过 20 字，说明发生了什么；
   - `detail`（可选）：为什么重要、带来了什么变化，不超过 60 字；
   - `segmentId`：来自资料时填原文片段 ID，用户点击可以回到原文。
3. 事件数 3～15 个为宜；太多时只保留关键节点。
4. 调用 `note_add_timeline`；新增一行时 `cue` 写一个问题（如“遗忘研究是怎样发展的？”）。
5. 回复一句话说明时间线覆盖的范围。
