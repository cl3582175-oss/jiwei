# 图表

图表只负责**数据**，配色、字体、深色模式由积微处理。

## 范围

内容来自一份较长的资料、而用户没说清是哪部分时：先用 `source_outline` 看规模与章节，再用 `ask_user` 让用户选（当前页 / 某一章 / 整份资料 / 指定页码），不要默认只用当前可见部分。范围超过约 40 段时，用 `source_read` 分几次读完再整理；只读了一部分时，在结果里注明依据的页码或章节。

## 选图

| 想表达 | 用 |
| --- | --- |
| 类别之间比大小 | `bar` |
| 随时间的变化趋势 | `line`（categories 按时间顺序） |
| 部分占整体的比例（不超过 7 块，总和有意义） | `pie` |
| 两个变量的关系 | `scatter`（data 为 `[x, y]` 数对） |
| 同一对象在多个维度上的表现（3～8 个维度） | `radar` |

## 规则

1. **数字必须有依据**：来自资料 / 笔记的，回答中标注编号；资料中没有具体数字时，**不要编造**，改为说明“资料中没有数据”，或改用表格 / 图示表达。
2. 除 `scatter` 外，每个系列的 `data` 数量必须与 `categories` 数量**完全一致**。
3. `title` 简短说明图表内容；坐标轴有单位时写进 `xLabel` / `yLabel`（如“遗忘比例（%）”）。
4. 数据来源写进 `note`（如“数据：艾宾浩斯 1885 年实验”）。
5. 调用 `note_add_chart`；新增一行时 `cue` 写这张图回答的问题。
6. 回复一句话说明图表展示了什么。

## 示例

```json
{
  "type": "line",
  "title": "艾宾浩斯遗忘曲线",
  "categories": ["20 分钟", "1 小时", "9 小时", "1 天", "2 天", "6 天", "31 天"],
  "series": [{ "name": "记忆保持率", "data": [58, 44, 36, 34, 28, 25, 21] }],
  "yLabel": "保持率（%）",
  "note": "数据：艾宾浩斯（1885）"
}
```
