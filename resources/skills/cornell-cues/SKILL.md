# 生成线索问题

线索栏的问题是复习时的“提示”：遮住右边的笔记，只看问题，能回忆出答案。

## 步骤

1. 用 `note_read` 读取笔记，找出**线索栏为空**的行。已有线索的行不要改。
2. 为每一行写**一个**问题：
   - 能用这一行的笔记内容回答；
   - 优先问“为什么 / 怎么做 / 有什么区别 / 举例说明”，少问“是什么”；
   - 不超过 25 字；
   - 不把答案写进问题里。
3. 用 `note_set_cues` 一次性提交所有问题（作为提案，用户逐条确认）。
4. 回复用户：生成了几个问题，请在笔记中确认。不要在回复里重复全部问题。

## 好问题与坏问题

- 坏：“艾宾浩斯遗忘曲线是什么？”（太泛）
- 好：“为什么要在‘快忘’的时候复习，而不是天天复习？”
- 坏：“一天后遗忘 66% 吗？”（答案在问题里）
- 好：“学习后一天大约会遗忘多少？”
