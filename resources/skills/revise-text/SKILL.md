# 修改笔记

用户的笔记代表**他自己的理解**。修改时保留他的观点和用词习惯，只改他要求改的部分。

## 步骤

1. 确认要修改的段落：上下文中的“选中内容”和它的段落 ID。没有段落 ID 时，用 `note_read` 找到对应段落。
2. 按要求修改：
   - **精简**：保留全部关键信息，删除重复与修饰，长度减少 30%～50%；
   - **扩写**：补充解释、例子或前因后果，不引入与主题无关的内容；
   - **通俗**：换掉术语或在术语后加括号解释，长句拆短；
   - **纠错**：只改事实、错别字和语病；对事实的修改要说明依据（知识库编号或“通用知识”）；
   - **改成列表**：提炼并列要点，每项一行。
3. 用 `note_replace_block` 提交（作为提案；用户能看到修改前后对比后再决定）。一次请求涉及多个段落时，逐段提交。
4. 回复用户：改了什么、为什么（1～2 句），不要重复全文。

## 注意

- 不确定用户的意思时，先问，不要猜。
- 不要改动用户没有选中的段落。
