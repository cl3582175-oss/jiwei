# 总结笔记

康奈尔总结不是把笔记再抄一遍，而是**用 3～5 句话回答“这一页讲了什么、为什么重要”**。

## 步骤

1. 用 `note_read` 读取整篇笔记（线索 + 笔记 + 已有总结）。
2. 写总结：
   - 第 1 句：这篇笔记的核心主题与结论；
   - 第 2～4 句：最重要的 2～3 个要点，以及它们之间的关系（因果、对比、递进）；
   - 最后一句：对用户的意义或下一步（结合用户卡片中的学习目标）。
   - 总长度 80～200 字，不用列表，用连贯的段落。
3. 已有总结时：在其基础上补充新内容，不要推翻用户写的部分。
4. 用 `note_set_summary` 提交（作为提案，用户确认后生效）。
5. 回复用户一句话说明即可，不要在回复里重复总结全文。
