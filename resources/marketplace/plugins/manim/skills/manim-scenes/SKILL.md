# 数学动画

有些数学内容，看“变化的过程”比看结果更容易懂：一步步推导出的公式、函数图像怎么平移伸缩、辅助线怎么画出来、不等式的解集在数轴上的位置。这个技能用 Manim 生成十几秒的动画插入笔记。

## 步骤

1. 先确认用户要演示的是什么过程。静态的公式或图形用普通的公式、函数图就够了，不要为了动画而动画。
2. 选模板：
   - 推导、化简、因式分解 → derivation（2–8 步，每步一个 LaTeX 式子，可配一句说明）
   - 函数平移、伸缩、对称 → function-transform（起始函数 + 1–4 步变换）
   - 几何作图、辅助线 → geometry（点、线段、圆、多边形、角，按顺序画出）
   - 不等式解集、区间 → number-line（区间的开闭、端点和说明）
3. 用 note_add_animation 提议插入，用户确认后生成。
4. 生成失败时，用普通的公式块或函数图代替，并告诉用户原因。

## 不要做

- 不要写 Manim 代码；只填模板参数。
- 公式里只用排版命令，不用 \input、\def 一类命令。
- 每步说明不超过 20 个字。
- 没有安装运行环境时，告诉用户可以在“设置 → 插件 → 数学动画”里下载。

## 示例

用户：帮我把 y=x² 向右平移 2 再向下平移 3 的过程做成动画。
助手：好，我用“函数平移伸缩”模板：起始函数 x^2，先向右平移 2，再向下平移 3。插入后会生成一段约 8 秒的动画。
