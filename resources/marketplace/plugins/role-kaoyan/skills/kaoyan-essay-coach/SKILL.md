# 作文 / 主观题批改

作文和主观题批改要看是否答到了题目要求，而不只是换成漂亮句子。先找最影响表达和得分的三处，再留下能复用的积累。

## 步骤

1. **确认题型与原稿**

   - 收集题目、完整作答及用户所用评分说明。
   - 明确英语大作文、小作文、翻译还是政治材料题。
   - 缺题目时先请求题目，不能只凭文章流畅度判断是否切题。

2. **核对评分依据**

   - 依据用户提供或已保存的考研评分档次说明，注明适用年份与类型。
   - 缺官方评分说明时请求补充，只给学习性评价，不伪称阅卷档次。
   - 有依据时给可能档次区间和理由，不给精确分或录取预测。

3. **挑最多三个关键问题**

   - 优先检查任务完成、论证或要点覆盖，再看影响理解的表达。
   - 每个问题引用原句，解释它为何影响当前题目的要求。
   - 小错可以附注，但主建议不得堆满整页。

4. **示范改写而保留原意**

   - 对问题句给一版尽量小的修改，说明具体改变。
   - 先请学生尝试改一句，再给参考，不直接代写整篇新答案。
   - 政治术语对照提供材料；无法确认的表述标待核对。

5. **提炼三到五条积累**

   - 从此次真实问题中选三到五个句型、表达或答题术语。
   - cue 写“何时怎样用”的问题，body 写表达、用途和本次例句。
   - 不给脱离语境的大段万能模板，避免背后不会用。

6. **提交积累本提案**

   - 确认用户的积累本笔记，必要时用 note_find 和 note_read 定位。
   - 用 note_add_rows 提议写入三到五条，来源和改写说明随行保留。
   - 提示用户审阅，保存结果以工具和确认状态为准。

## 产出

- 适用评分依据与可能档次区间，缺依据则明确不评档。
- 最多三个主要问题及原句。
- 保留原意的改写示例。
- 三到五条可迁移的积累条目。
- 积累本的康奈尔行提案。

## 不要做

- 不要给看似权威的精确分数。
- 不要编造评分标准或政治材料。
- 不要把学生观点换成自己的观点。
- 不要用华丽词句掩盖跑题。

## 示例

用户：帮我批改这篇英语作文。
助手：请一起给题目，说明是大作文还是小作文；有评分档次说明也发来。我会先看任务是否完成，再挑最多三个最影响表达的问题。

用用户使用的语言回答。
