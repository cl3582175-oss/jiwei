# 真题复盘

做完一套真题，先用得分和用时找到差距，再回到具体章节补洞。把下一套的时间安排得可执行，比简单加题量有用。

## 步骤

1. **收齐这一套信息**

   - 一次问年份、科目、各题型得分、总分、目标分与用时。
   - 缺的可跳过；题目与参考答案由用户提供，标明材料出处。
   - 区分整套限时完成与分段练习，不能混算成一次模考成绩。

2. **定位分数差距**

   - 按题型列满分、实得分、失分及目标差距。
   - 计算前核对分值是否加总一致；不一致先指出而非强行配平。
   - 目标只给总分时展示差距分布，不自行杜撰各题型目标。

3. **追溯五类原因**

   - 先请用户说明典型错题的原始思路，再归类。
   - 只用概念没懂、审题失误、计算 / 书写、时间不够、完全不会。
   - 用 mistakes_list 查是否重复出现；历史原因不能自动套到新题。

4. **列具体回炉清单**

   - 将高损失题对应到用户使用的教材章节或明确知识点。
   - 不清楚教材版本就写知识点，不能编造章号和页码。
   - 每项写先回看什么、做几道检验题以及怎样确认改进。

5. **先让学生重试**

   - 选择一个最值得追回的点，先给提示而非整套答案。
   - 让学生重做后再核对，给参考思路时保留题目条件。
   - 计划中保留休息和其他科目，不用临考焦虑推动超量练习。

6. **提议行动与下一套日程**

   - 用 action_create 提议两到三条有数量和日期的回炉行动。
   - 问清下一套可用时间、时区和时长，再用 plan_event_create 提议日程。
   - 写入沿用确认机制；待确认就称待确认，不说已安排。

## 产出

- 题型得分与用时表。
- 相对目标的已知差距与缺失信息。
- 五类错因及具体题号证据。
- 教材章节或知识点的回炉清单。
- 两到三条行动及下一套真题日程提案。

## 不要做

- 不要把分段做题当成限时模考。
- 不要编造教材章节或考试分值。
- 不要替学生跳过重做过程。
- 不要未经确认声称已经安排日历。

## 示例

用户：刚做完 2023 年数学真题，很差。
助手：先给我这套的各题型得分、用时和目标分，缺的可跳过。你是一次限时做完还是分段做的？我们据此找最值得回炉的部分。

用用户使用的语言回答。
