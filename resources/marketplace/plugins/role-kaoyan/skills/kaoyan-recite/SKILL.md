# 政治 / 专业课背诵

政治和专业课背诵最终要能在考场上组织答案。把材料变成问题，再练关键词与展开句，避免只会认得不会说。

## 步骤

1. **确定材料和答题类型**

   - 请用户提供实际要背的文本或笔记，说明科目与时间目标。
   - 用 note_read 读取指定笔记，缺 ID 先用 note_find 找到。
   - 名词解释和材料论述分别处理；不能凭书名生成未提供的资料。

2. **拆成五到九块**

   - 按逻辑分成五到九块，每块提炼关键词。
   - 保留原文的定义、限定条件和因果顺序。
   - 材料规模不适合时先调整本次范围，不机械凑块。

3. **改成提取式问题**

   - 每块一到两个问题，cue 只写题目，不泄露答案。
   - 普通答题 body 用“关键词 + 一句展开”的结构。
   - 名词解释 body 用“定义 + 特征 + 意义”三段，缺哪段就注明材料未给。

4. **先试背再校正**

   - 先给一个问题，请学生遮住材料口头或文字回答。
   - 对照原文指出漏了哪个关键词、条件或展开，不只说不完整。
   - 学生尝试后再展示参考答案，明确是所给材料的整理。

5. **提议积累成笔记行**

   - 确认新建或现有目标笔记，不编造 noteId。
   - 用 note_add_rows 提议写入题目与答案，单批最多二十行。
   - 保留可用来源标识，无法确认的表述不作为定稿。

6. **说明后续复习**

   - 告诉学生“先遮住答案自己说，说不出再看”。
   - 写入后的线索会自动成为复习卡，按现有间隔复习安排。
   - 建议每次检查关键词和展开是否连得起来，不额外创建重复提醒。

## 产出

- 五到九个背诵小块。
- 每块一到两个提取问题。
- 关键词加展开句的答案。
- 名词解释按定义、特征、意义成段。
- 康奈尔背诵笔记提案及使用说明。

## 不要做

- 不要复刻用户未提供的付费材料。
- 不要编造政治表述或权威答案。
- 不要在提问时先揭晓答案。
- 不要声称提案已保存或永久掌握。

## 示例

用户：帮我背专业课这些名词解释。
助手：把实际内容或笔记发来。我会按定义、特征、意义拆开，先挑一个让你遮住答案说，再一起找漏掉的关键词。

用用户使用的语言回答。
