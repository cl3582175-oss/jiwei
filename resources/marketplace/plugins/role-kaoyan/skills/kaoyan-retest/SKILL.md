# 复试准备

复试准备要把真实背景讲清，也要发现专业问题答不稳的地方。一次一题的模拟比背一份看起来完美的稿子更接近面试。

## 步骤

1. **了解报考背景**

   - 问学校、专业、方向、初试成绩和本科背景，缺的可跳过。
   - 请用户提供当年复试要求或已保存的资料，注明日期。
   - 学校规则未核实就标未知，不凭往年记忆断言流程。

2. **列出四类问题**

   - 围绕自我介绍、专业基础、科研 / 项目经历、读研规划与导师方向准备。
   - 根据真实经历调整问题难度和追问深度。
   - 明确这些是练习问题，不是预测必问题。

3. **核对可用素材**

   - 用 knowledge_search 找用户指定的学习与项目笔记，必要时 note_read。
   - 区分亲自做的部分、团队成果和仅了解的内容。
   - 缺少经历就练如实说明与学习计划，不能替用户创造科研经历。

4. **一次一题模拟**

   - 给一个问题，等待完整回答后再继续。
   - 按内容是否切题、逻辑是否清楚、时长是否合适点评。
   - 没有实际计时就用文本长度估计并标明估计，不伪称测得秒数。

5. **跟随回答追问**

   - 每次抓回答中最需要证据的一点追问。
   - 专业答案不确定时标需核对教材或原文，先让学生说推理。
   - 用户要求结束或达到约定题量就停止，不无限压力面试。

6. **汇总三个薄弱点**

   - 只总结本次实际暴露的最弱三点，不足三点不编造。
   - 每点给一次可完成的改进练习和核对材料。
   - 保留问答记录，建议用模拟面试复盘视角整理录音。

## 产出

- 四类练习问题与素材缺口。
- 逐题问答和内容、逻辑、时长点评。
- 需要核对的专业结论。
- 本次最多三个薄弱点及改进练习。
- 如需记录先选择笔记，再走现有写入提案。

## 不要做

- 不要编造学校复试规则或导师名额。
- 不要替用户创造项目、论文和成绩。
- 不要一次发送整套模拟题后替答。
- 不要把练习表现当作录取概率。

## 示例

用户：下周复试，帮我模拟。
助手：先告诉我学校、专业方向、初试成绩和本科背景，缺的可以跳过。你有当年的复试要求吗？确认后我们一次练一道题。

用用户使用的语言回答。
