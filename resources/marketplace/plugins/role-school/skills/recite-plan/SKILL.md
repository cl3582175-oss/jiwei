# 背诵冲刺

要背的东西很多时，把它变成能遮住答案自问的小块，比反复盯着整页更容易发现哪里还说不出来。

## 步骤

1. **确认材料与范围**

   - 请用户给要背的文字或指定笔记，说明希望何时能背出。
   - 指定笔记用 note_read 读取；不知道 ID 时用 note_find 找到后再读。
   - 只处理用户提供或可读到的材料，不凭记忆补教材原文。

2. **切成五到九块**

   - 先列五到九个有意义的小块，保留原文的顺序或逻辑。
   - 每块提炼少量关键词，标出容易混淆的字词或条件。
   - 材料太短或太长时先征得范围调整，不把一句话机械切碎凑数。

3. **设计提取问题**

   - 每块出一到两个必须回想才能答的问题，避免只问“记住了吗”。
   - 问题放 cue，答案放 body；古诗文保留准确原句，单词保留语境。
   - 先让用户试答一个小块，根据答不出的地方调整问题粒度。

4. **核对问题与答案**

   - 检查每个问题只有一个清楚目标，答案能在材料里找到。
   - 对于近义词、时间顺序、因果关系，直接问区别而不是照抄标题。
   - 不确定的字词标待核对，不能把猜测写成标准答案。

5. **提议写入康奈尔行**

   - 确认目标笔记；没有笔记时引导先新建或选择一篇。
   - 用 note_add_rows 提议写入 cue/body，每次不超过工具允许的二十行。
   - 有来源段落 ID 就使用真实 ID 关联，确认前不声称保存。

6. **说明怎么开始背**

   - 告诉用户“先遮住答案自己说，说不出再看”。
   - 说明康奈尔线索写入后会成为复习卡，后续按积微间隔复习安排。
   - 不自行创建一套重复提醒；卡片效果取决于用户确认写入和实际复习。

## 产出

- 五到九个小块及各自关键词。
- 每块一到两个提取式问题，答案与题目分栏。
- 标明出处和待核对的字词。
- 目标笔记中的康奈尔行提案。
- 最后给一句实际开始背诵的方法。

## 不要做

- 不要把问题写成已经含答案的提示。
- 不要篡改古诗文或伪造教材原句。
- 不要代替用户完成第一次回忆。
- 不要承诺已创建复习卡或另起重复排期。

## 示例

学生：这页历史知识点要背下来。
助手：把这页内容或笔记发给我，我先帮你拆成小块。你希望哪天能背出？我们先用其中一块试着遮住答案说一遍。

用用户使用的语言回答。
