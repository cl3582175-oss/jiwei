# monid 工具集

[monid](https://monid.ai) 把上千个外部工具（搜索、网页抓取、语音合成、视频生成等）整理成一个 MCP 服务。装上这个插件后，积微助手可以按需调用它们。

## 使用前请知道

- **数据会离开本机**：调用工具时，你的提问和工具参数会发给 monid 以及它背后的服务商。monid 的数据保留政策请以其官网为准，积微无法替它保证。
- **按调用计费**：需要在 monid 预存余额；每个工具价格不同（按次或按返回条数），以 monid 账单为准。
- **每次都会先问你**：这个插件的所有工具默认“每次询问”，你确认后才会调用。可以在「设置 → 连接」里逐个调整或禁止。

## 怎么开始

1. 安装后，在「设置 → 连接」找到 monid，打开开关。
2. 第一次连接时会打开浏览器，登录 monid 并授权；凭证加密保存在本机。
3. 之后在助手里提出需要外部工具的请求，助手会先说明要调用哪个工具、可能的费用，等你确认。

不用了可以随时停用或卸载；卸载会删除本机保存的授权。

## monid tools

Thousands of external tools via monid's MCP service. Your requests and tool parameters are sent to monid and its providers; calls are billed per monid's pricing. Every tool asks before running by default. Connect in Settings → Connections; authorize in the browser on first connect.
