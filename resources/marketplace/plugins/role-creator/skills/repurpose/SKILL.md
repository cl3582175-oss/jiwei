# 一稿多用

一稿多用是改变讲述节奏与呈现方式，不是顺手增加新事实。先抓住原稿的核心，再让每个平台版本有自己的结构。

## 步骤

1. **确认原稿与目标格式**

   - 请用户给完整原稿，指定笔记时用 note_read。
   - 问要改成短视频口播、图文卡片还是推文串。
   - 记录不能删的事实、出处与用户希望保持的语气。

2. **提炼核心材料**

   - 提取不超过三个核心观点和最好的一例。
   - 为每个观点记录原稿位置与引用来源。
   - 素材没有例子就说明缺少，不编造案例、数据或用户故事。

3. **按格式重排**

   - 短视频六十到九十秒，前三秒抓住问题，每句短。
   - 图文六到九张，每张一个观点；推文串五到八条。
   - 只做用户选择的目标版本，时长用口播估算并标明需试读。

4. **保留事实和出处**

   - 改写不改变数字、限定条件和引语意思。
   - 引用在短格式中保留可追溯的简短来源说明。
   - 原稿已有不确定说法仍保留不确定性，不能润色成定论。

5. **检查阅读节奏**

   - 视频用自然停顿和镜头提示，卡片检查每张是否独立可懂。
   - 推文串每条推进一点，不把长句机械截断。
   - 删减后若论据不足，就缩小主张而非补未经证实的新内容。

6. **交付与后续创作**

   - 提供目标版本及删改说明，列需要用户核对的素材。
   - 需要成作品时建议相应短视频或卡片模板，不承诺已渲染。
   - 用户确认后才通过笔记提案保存，不自动发布外部平台。

## 产出

- 目标平台版本，满足数量或时长范围。
- 核心观点不超过三个，保留最佳例子。
- 事实、限定条件和出处可追溯。
- 列出删改与待核对内容。
- 可进一步进入作品创作，发布由用户决定。

## 不要做

- 不要新增原稿没有的事实和数字。
- 不要把估算口播时长说成已测量。
- 不要把引语改写后继续放引号。
- 不要自动发布或承诺传播效果。

## 示例

用户：把这篇长文改成短视频。
助手：请给完整原稿。我会保留最多三个核心观点和一个最好例子，做成六十到九十秒口播稿；原稿的事实和出处都会保留。

用用户使用的语言回答。
