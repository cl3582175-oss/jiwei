# 从笔记里挖选题

选题不一定要追热搜。先看自己已经保存、经历和思考过的东西，找到能用真实素材讲清的五个角度。

## 步骤

1. **确认读者与范围**

   - 问内容平台、目标读者和希望覆盖的笔记时间范围。
   - 未指定范围就从最近笔记开始，说明这只是当前可读材料。
   - 不要把用户未开放给 AI 的笔记列为素材。

2. **找到实际材料**

   - 用 knowledge_search 和 note_find 找笔记、资料与收藏。
   - 用 note_read 或 source_read 核对候选内容，保留真实 ID 和标题。
   - 搜索摘要不足以支撑论点时继续读，不从标题编故事。

3. **沿四种来源找线索**

   - 分别找反常识的发现、亲身经历与踩坑、读者常问的问题。
   - 再找两篇笔记之间的意外联系，明确关联依据。
   - “亲历”和“读者常问”必须有真实记录，否则标为待验证角度。

4. **写成五张选题卡**

   - 每张包含一句话主题、目标读者、钩子、可用素材和形式。
   - 钩子解释为什么现在值得看，不制造虚假紧迫感。
   - 形式选择长文、视频或卡片，说明为什么适合现有材料。

5. **按素材充足度排序**

   - 优先每个关键论点都有素材和具体例子的题。
   - 给每张列还缺什么证据，素材不足五张时保留缺口说明。
   - 关联只是推测就标为创作假设，不包装成科学发现。

6. **让用户选一个继续**

   - 用一两句说明最适合先做的题，但由用户选择。
   - 需要保存时确认笔记，再用 note_add_rows 提议写入选题卡。
   - 不自动发布、不杜撰阅读量，也不把生成数量当作选题质量。

## 产出

- 五张按素材充足度排序的选题卡。
- 主题、读者、钩子、素材出处、形式齐全。
- 标明属于四种来源中的哪一类。
- 缺口和创作假设单列。
- 用户可挑一张继续写作或保存提案。

## 不要做

- 不要从笔记标题虚构用户经历。
- 不要编造读者提问和热点数据。
- 不要把两篇笔记的关联当作因果证明。
- 不要为了凑五个写无素材的空题。

## 示例

用户：最近写什么好？
助手：你准备发在哪个平台、主要给谁看？我会从最近笔记里找反常识、亲历踩坑、读者问题和意外联系，再按素材够不够排五个选题。
