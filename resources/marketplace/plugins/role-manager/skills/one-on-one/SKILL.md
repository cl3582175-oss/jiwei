# 一对一

一对一先留空间给对方关心的事，再跟进已经答应的事。提前准备具体反馈能减少临场评价人，而忽略真正的工作障碍。

## 步骤

1. **确认对象和会谈**

   - 问对方是谁、本次一对一时间和希望讨论的情况。
   - 用 knowledge_search 查此人相关笔记与上次一对一记录。
   - 有重名或角色不清先核对，不把不同人的信息混在一起。

2. **找未完成承诺**

   - 用 actions_list 查相关未完成行动，再读对应笔记核对。
   - 区分我承诺给对方的事与对方承诺的事，保留日期出处。
   - 缺完成状态写待确认，不由时间已过推断未履行。

3. **排一个可调整议程**

   - 最前面留“对方想聊的”，不要替对方填好全部内容。
   - 随后是上次承诺跟进、反馈、成长、阻碍。
   - 按会谈可用时间分配，允许对方最关心的话题占更大空间。

4. **写具体反馈草稿**

   - 用 SBI：情境、可观察行为、造成的影响，写成一句话。
   - 只用记录中的具体事例；影响是推断时标注并准备询问。
   - 不用性格判断，不揣测动机或情绪。

5. **准备开放问题**

   - 围绕成长目标、当前阻碍和需要的支持提两到三个问题。
   - 每题能让对方表达，不用暗示答案的审问句。
   - 需要说明限制时写清能提供什么、需要进一步确认什么。

6. **说明会后怎样跟进**

   - 提醒可用“一对一”视角整理录音中的关切与承诺。
   - 确认事项后用 action_create 提议行动项，负责人和日期必须来自明确约定。
   - 没有发生的会议不写成纪要，提案未确认不说已保存。

## 产出

- 对方议题留在最前的会谈议程。
- 未完成承诺按双方区分，附证据。
- 一句具体的 SBI 反馈草稿。
- 两到三个成长或阻碍问题。
- 会后录音整理与行动提案建议。

## 不要做

- 不要把一对一变成单向进度盘问。
- 不要猜对方情绪或动机。
- 不要混淆同名人员或承诺归属。
- 不要把建议和未确认事项写成已承诺待办。

## 示例

用户：明天和小李一对一，帮我准备。
助手：这次大约多久，你最想了解什么？我先找上次记录和未完成承诺，但议程第一项会留给小李自己想聊的事。

用用户使用的语言回答。
